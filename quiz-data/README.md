# 中学受験対策 4択クイズデータ

## 概要

このディレクトリには、中学受験対策のための4択クイズデータが格納されています。全教科（国語、算数、理科、社会）の主要分野を網羅し、基礎から発展まで4段階の難易度に分類されています。

## ディレクトリ構造

```
quiz-data/
├── README.md（このファイル）
├── kokugo/（国語）
│   ├── 01_知識語彙_書き取り.json
│   ├── 02_知識語彙_同音異義語.json
│   └── 03_熟語慣用表現_四字熟語.json
├── sansu/（算数）
│   ├── 01_基礎計算_四則計算.json
│   └── 02_特殊算_つるかめ算.json

│   ├── 01_物理_てこの原理.json
│   └── 02_化学_水溶液.json

    └── 02_歴史_古代.json
```

## データ構造

各JSONファイルは以下の構造を持ちます：

```json
{
  "metadata": {
    "subject": "教科名",
    "category_large": "大分類",
    "category_small": "小分類",
    "version": "バージョン",
    "last_updated": "更新日"
  },
  "quizzes": [
    {
      "id": "一意のID",
      "subject": "教科名",
      "category_large": "大分類",
      "category_small": "小分類",
      "difficulty": "難易度",
      "question": "問題文",
      "options": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
      "answer": 正解のインデックス（0-3）,
      "explanation": "解説"
    }
  ]
}
```

## 難易度の定義

| 難易度 | 説明 |
|:------|:-----|
| **基礎** | 基本的な知識・暗記項目。小学校の教科書レベル |
| **標準** | 一般的な中学受験レベル。中堅校の入試問題レベル |
| **応用** | 複数知識の統合が必要。難関校の入試問題レベル |
| **発展** | 高度な思考力が必要。最難関校の入試問題レベル |

## 使用方法

### データの読み込み

```javascript
// Node.jsでの例
const fs = require('fs');
const quizData = JSON.parse(
  fs.readFileSync('quiz-data/kokugo/01_知識語彙_書き取り.json', 'utf8')
);

console.log(quizData.quizzes.length); // クイズの数
console.log(quizData.quizzes[0]); // 最初のクイズ
```

### 特定の難易度のクイズを抽出

```javascript
const basicQuizzes = quizData.quizzes.filter(
  quiz => quiz.difficulty === '基礎'
);
```

### ランダムにクイズを選択

```javascript
function getRandomQuiz(quizzes) {
  const randomIndex = Math.floor(Math.random() * quizzes.length);
  return quizzes[randomIndex];
}

const randomQuiz = getRandomQuiz(quizData.quizzes);
```

## データの追加・更新

新しいクイズを追加する際は、以下の点に注意してください：

1. **IDの一意性**: 各クイズのIDは教科内で一意である必要があります
2. **フォーマットの統一**: metadata と quizzes の構造を維持してください
3. **選択肢の数**: 必ず4つの選択肢を用意してください
4. **解説の充実**: 正解の理由と関連知識を含めてください
5. **難易度の適切な設定**: 問題の難しさに応じて適切な難易度を設定してください
